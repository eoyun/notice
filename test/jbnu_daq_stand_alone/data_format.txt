<Fast data format>
========================================================
Data length = 256				4 byte
--------------------------------------------------------
Run number					2 byte
--------------------------------------------------------
Trigger type					1 byte
--------------------------------------------------------
TCB trigger number				4 byte
--------------------------------------------------------
TCB trigger fine time				1 byte
--------------------------------------------------------
TCB trigger coarse time				3 byte
--------------------------------------------------------
Module ID(= 10)					1 byte
--------------------------------------------------------
channel #(= 0)					1 byte
--------------------------------------------------------
Local trigger number				4 byte
--------------------------------------------------------
Local trigger pattern				4 byte
--------------------------------------------------------
Local gate fine time				1 byte
--------------------------------------------------------
Local gate coarse time				6 byte
--------------------------------------------------------
Ch1 charge					3 byte			
--------------------------------------------------------
Ch1 timing					2 byte
--------------------------------------------------------
Ch1 flag(hit)					1 byte
--------------------------------------------------------
....
--------------------------------------------------------
Ch32 peak					3 byte			
--------------------------------------------------------
Ch32 timing					2 byte
--------------------------------------------------------
Ch32 flag(pile_up & hit)			1 byte
--------------------------------------------------------
Empty(all 0)				       32 byte			
========================================================

<Waveform data format>
========================================================
Data length = 8192				4 byte
--------------------------------------------------------
Run number					2 byte
--------------------------------------------------------
Trigger type					1 byte
--------------------------------------------------------
TCB trigger number				4 byte
--------------------------------------------------------
TCB trigger fine time				1 byte
--------------------------------------------------------
TCB trigger coarse time				3 byte
--------------------------------------------------------
Module ID(= 10)					1 byte
--------------------------------------------------------
channel #					1 byte
--------------------------------------------------------
Local trigger number				4 byte
--------------------------------------------------------
Local trigger pattern				4 byte
--------------------------------------------------------
Local gate fine time				1 byte
--------------------------------------------------------
Local gate coarse time				6 byte
--------------------------------------------------------
Waveform data[0]				2 byte
--------------------------------------------------------
....
--------------------------------------------------------
Waveform data[n-1]				2 byte
========================================================
